🚀 CYBER MIND SPACE
Advanced Bug Bounty Hunting Platform

CYBER MIND SPACE is a fully interactive, browser-based platform designed for security researchers, bug bounty hunters, and ethical hackers.
It helps you write notes, track labs, measure learning progress, and practice cybersecurity concepts — all in one place.

The platform runs locally in the browser using JavaScript and localStorage, requiring no backend, no database, and no server setup.

📌 Features
📝 1. Security Notes Manager

Create, edit, delete, and organize notes

Auto-saved to localStorage

Export notes to PDF

Upload PDFs into the notes system

Smooth neon-styled UI with animations

Expert

Built-in search + difficulty filter
